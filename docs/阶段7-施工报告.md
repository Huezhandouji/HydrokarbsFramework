## 三、各子阶段交付

### 7.1 MiniGameApi 冻结面(★19 首建)

- `api/MiniGameApi.java`:v1 冻结面 **8 方法**(查询 3:`sessionOf`/`session`/`sessions`;控制 2:`switchMode`/`createSession(两参)`;目录 3:`modes`/`maps`/`mode`);javadoc 含 A9 三限制、线程契约表、战绩面悬置注。
- `api/view/` 三个不可变快照 record:**`SessionInfo`**(sessionId/modeId/mapId/members/state;无实例空串口径)、`MatchModeInfo`(displayName/description 经 MiniMessage 序列化,枚举存 `name()`)、`MapInfo`(按 MapDefinition 实际字段映射)。
- `api/MiniGameApiImpl.java`:薄委托 SessionService/MatchModeRegistry/MapRegistry + 注入式主线程执行器;会话不存在 → future 完成 `Rejected(MODE_NOT_FOUND)`;目录顺序 = 注册序,不排序不过滤(14.21)。
- `HydrokarbsAssembly`:ServicesManager 注册(`ServicePriority.Normal`)/ shutdown 幂等注销,Context 增字段。
- 测试:`MiniGameApiSurfaceTest`(★19,8 签名反射冻结 + 只增不改运营细则)、`MiniGameApiImplTest`(快照不变性/缺失会话/主线程发起/目录序/createSession 响亮抛/视图无引擎活类型)。
- 全量 227 项 0 失败;`engine/**` 与既有 `component/**` 对基线 diff 为空(★5 口径)。

- 全量 238 项 0 失败;三连门禁绿。

### 7.5 API 面扩充与拆分彩排(★41~★46 / ★51~★55 首建,G1)

- **包根更名(D13)提前满足**:工程自始 `com.hydrokarbs`,全库 grep `com.shdf.match` 零命中,无迁移 PR。
- `MiniGameApi` 扩至 **v3(API_VERSION=3,16 方法,只增不改;v1 面 8 方法签名一字不动)**:成员操作 `joinSession`/`leaveSession`(D2)、事件订阅 `subscribeSessionEvents`(D3)、能力标签 `registerCapability(Plugin,String)`/`capabilities()`(D4)、`createSession(SessionRecipe)` 重载(D14 通道二)、地图注册 `registerMap`/`unregisterMap`(★v1.2)。
- api 新类型四件:`EventSubscription`、`SessionEventView`(sealed 八 record,对齐引擎 SessionEvent 八事件;枚举存 `name()`)、`SessionRecipe`、`SessionComponentProvider`;`MatchModeProvider#requiredApiVersion()` 默认方法;框架 onEnable 输出 API_VERSION 并记录各 Provider 要求。
- **D3 聚合挂接 + ⑨ 悬空修复**:`SessionEventBus` 加性镜像点 → `HydrokarbsAssembly` ⑨ 号全局汇聚总线(此前只有服务订阅、无人喂事件)→ `MiniGameApiImpl` 订阅全局总线做快照转换;公开签名零改动,镜像异常隔离;GlobalBoard/GlobalLedger 至此真正收到事件。
- D4:提供方归属(Plugin→tags)实现在 api 层伴生(`CapabilityRegistry` 保持 tag-only 既有口径),`ProviderUnloadListener` 兜底 disable 摘除。
- D14:provider 收录(干跑合并校验:查重+依赖,坏 provider SEVERE 拒收录、会话照常);`createSession(SessionRecipe)` 合并序 = 宿主表 → provider(注册序)→ recipe.extra。
- 地图注册通道:`MapRegistry` 双输入 `register(Object,MapDefinition)`/`unregister(Object,String)`(provider 键用 Object,map 包保持零 Bukkit 依赖)汇入同一私有 `register()`、同一命名空间;注册期校验 id 查重(点名先到者)/tags/模板目录存在性;卸载守卫(会话正用 → 拒;幂等);注册式不经 reload。
- 测试:`ApiSurfaceTest`(★44,白名单逐包清单 + 双断言:签名零非白名单类型/白名单公开签名快照只增不改)、`MiniGameApiSurfaceTest` 8→16、`MiniGameApiMembersTest`/`MiniGameApiEventsTest`(★42/★43)、`SessionComponentContributionTest`(★51~★53)、`MapRegistrationTest`(★54~★55,@TempDir 离线)、`LayeringTest` ★40 增款(服务不得 import `api/**`,14.37)。
- `examples/TheirPlugin` 升级真实消费样例:onEnable 首行 API_VERSION 检查(拒载,14.36)、成员编排/事件订阅(句柄 onDisable close)/能力注册/SessionRecipe 命令、坏 provider 与低版本拒载用例、**禁 shade 构建断言**(jar 无 `com/hydrokarbs/` 条目)、注册式地图(onEnable 顺序:解包模板→构造→注册,14.39)。
