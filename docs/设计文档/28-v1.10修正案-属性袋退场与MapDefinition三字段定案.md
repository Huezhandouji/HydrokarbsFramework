## 0. 一页摘要

**变更(四条决策,D1~D4)**:

① **D1 `AttributeBag` 全库退场**:`engine/AttributeBag`(`Key` record、`set/get/getOrDefault/has`、`bindComponent`、`isNamespaceCheckEnabled/setNamespaceCheckEnabled`)整类删除;各端口/容器的 `attrs()`/`attr()` 全链删除——`MatchModeInstancePort`、`Participant`、`SessionPort`、`MatchModeInstanceAccess`、`SessionView`、`MatchModeInstanceView`;`MatchModeInstance`/`Session` 的袋构造、授权表灌入与 `close()` 链同步消失。`Handoff` **不随退场**——它是独立的跨模式交接机制(类型化键值袋、键随主人、§3.3),仅类注中去掉与属性袋的类比措辞。

② **D2 `MapDefinition` 三字段定案**:`record MapDefinition(Path worldDirectoryPath, ResetStrategy resetStrategy, Object metadata)`——路径构造期 `toAbsolutePath().normalize()`,缺目录名(id 无从派生)响亮抛;`resetStrategy` 非空;二参便利构造 `(Path, Object)` 缺省 `REUSE_DIRTY`(23 号复用窗口闭环原样);**`metadata` 按引用存储、视为冻结**——本记录不做深拷贝,注册方注册后不得再改其内容,允许 `null`;id 仍 = 声明目录名(路径派生,目录查重/副本命名/钉图键三同一源,26-D3 问一续行)。

③ **D3 标签 = `TagProvider` 唯一约定**:`map/TagProvider{ Set<String> tags(); }`,`MetaAttributes.tags(Object)` 是唯一读口——`metadata` 实现 `TagProvider` 时取 `tags()` 的不可变拷贝,否则(含 `null`)返回空集;`tags()` 不得返回 `null`;空集 = 不被任何模式按标签选中(20-D3 口径)。约定键 `map.tags`/`map.reset-strategy` 与 `MetaAttributes` 写口(`set/frozen`)随属性袋退场。

④ **D4 公共面与冻结测试处置**:`MiniGameApi` 17 方法签名与 `API_VERSION = 7` 零改动;★44 BASELINE 合法重录(删 `AttributeBag` 及其 `Key`/方法行、各端口 `attrs()`/`attr()` 行,增 `TagProvider#tags()` 行与 `MapDefinition` 三分量/`id()` 行);★19 FROZEN 17 行不动;★26 就地注废止(bag 行为腿与 ArchUnit 腿随机制不存在,测试文件删除)、★63 的 bag 三口径半句就地注废止(机制面不存在);**不新增 ★ 编号**,计数维持 **65 条 = 框架 58 + SHDF 扩展线 3 + 联合 1(★32 废止)+ 宿主线 3**。

**不动**:切换管线(阶段 A3 标签过滤逻辑原样,词料改由 `TagProvider` 提供)、`WorldPort` 三法/引用计数/复用窗口(★58)/`deleteCopyDir` 唯一删除口、`TEMPLATE_RESTORE` 行为、`MapInfo` 三分量 `(id, tags, resetStrategy)`、`SessionRecipe` record 形状、24 号显式注册四法与 25 号桥接结论、27 号世界清场接缝。

## 1. 决策 D1~D4

### D1:`AttributeBag` 全库退场(零过渡窗口)

**决策**:删除属性袋机制的全部载体:

| 载体 | 处置 |
|---|---|
| `engine/AttributeBag`(`Key` record、`set/get/getOrDefault/has`、`bindComponent`、命名空间开关) | 整类删除 |
| `MatchModeInstancePort#attrs()`、`Participant#attrs()/attr(Key)` | 删除 |
| `SessionPort#attrs()`、`SessionView#attrs()` | 删除 |
| `MatchModeInstanceAccess#attrs()`、`MatchModeInstanceView#attr(Key)` | 删除 |
| `MatchModeInstance`/`Session` 的袋字段、授权表灌入、`close()` 链中的袋销毁 | 删除 |
| `map/MetaAttributes` 的 `set/frozen/TAGS/RESET_STRATEGY/resetStrategy(…)` | 删除,门面收为 `tags(Object)` 一个读口 |

**理由**:生产写路径为零(全库普查:`attrs().set(…)` 在 `src/main` 无调用点);读路径只剩一个门面一个约定键;保留「将来也许有人写」的假想 seam 与「状态唯一 = 字段 + 强类型读口」(§2.7/§2.8-决断三)冲突——同一状态不留第二份弱类型、无编译期检查的表达。判据同 21-D1/25-D1(零消费者机制件删除)。

### D2:`MapDefinition` 三字段定案(声明 = 真实消费面)

**决策**:`record MapDefinition(Path worldDirectoryPath, ResetStrategy resetStrategy, Object metadata)`:

- **构造即权威**:路径 `toAbsolutePath().normalize()` 规范化入库;缺目录名(id 无从派生)构造期响亮抛;`resetStrategy` 非空;
- **二参便利构造** `(Path, Object)`:`resetStrategy` 缺省 `REUSE_DIRTY`;第二参是 `metadata`,不是策略;
- **`metadata` 按引用存储、视为冻结**:本记录不做深拷贝,同一引用的后续变动对已注册声明可见;冻结由注册方履约(注册后不得再改),`null` = 无声明词料;
- **id = 声明目录名**(路径派生;目录查重/副本命名/钉图键三同一源,26-D3 问一续行)。

**理由**:框架对地图的全部消费 = 查重键(id)+ 按标签选图(tags,经 `TagProvider`)+ 副本处置(`ResetStrategy` 强类型字段);`resetStrategy` 放在弱类型词料里会让框架唯一消费的强类型枚举穿过 `Class<T>` 转换,且该约定键从未有生产写方。冻结不再靠拷贝与断言,改由「交出的值由交出方保证不再变」的契约承担(与 20-D1「交成品不交工厂」一致)。

### D3:`TagProvider` 唯一约定与标签读口

**决策**:`map/TagProvider{ Set<String> tags(); }`;`MetaAttributes.tags(Object metadata)` 唯一读口:

```java
public static Set<String> tags(Object metadata) {
    if (metadata instanceof TagProvider provider) {
        return Set.copyOf(provider.tags());       // 不可变拷贝
    }
    return Set.of();                              // 未实现 / null = 无标签
}
```

**理由**:词料是宿主的扩展面——框架只解释一个最小约定(一个方法),其余声明词料(展示名/轮换线索/赛程标签)原样携带、框架不解释;空集 = 不被任何模式按标签选中(20-D3)。

### D4:公共面、版本与冻结测试处置

**决策**:`MiniGameApi` 17 方法签名一字不动;`API_VERSION` **维持 7**(方法面零变化,破坏性在声明形状侧);★44 BASELINE 合法重录(删 `AttributeBag`/`Key`/各端口 `attrs()` 行,增 `TagProvider#tags()` 与 `MapDefinition` 三分量/`id()` 行),★19 FROZEN 17 行不动;★26 与 ★63 的 bag 口径按 §5 就地注废止;不新增 ★ 编号。

**理由**:方法面未变,版本常量不因声明形状再动(v1.8 已付 6→7);冻结测试的重录仅限「被删除类型/成员不再出现在白名单」与「新声明形状进入白名单」,不得顺手放宽其它签名。★26 的检验对象(`AttributeBag.Key` 跨包引用)在类删除后不存在,ArchUnit 腿无法保留;其「状态主人唯一」命题由 14.26(状态写入归属)+ 强类型读口纪律承接,不是放宽而是机制退场后的口径转换。
