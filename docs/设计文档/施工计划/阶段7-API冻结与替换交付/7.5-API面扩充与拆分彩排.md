## 1. 目标

执行 v1.1 的 **G1 闸门**:API 面扩充到位,并在**单 jar(形态 A)**内按跨 jar 纪律"彩排"——把边界守成铁的,物理拆分(G2,阶段8)只是换打包方式。交付:

1. **全库包根更名**(D13):`com.shdf.match` → `com.hydrokarbs`(全库 package/import、`plugin.yml` 的 `main:`、`META-INF/services` 路径、ArchUnit/冻结测试包名模式、14.35 断言前缀),与 API_VERSION 1→2 同批一次付清;字符串域(Handoff 键/DB schema/配置路径与键/能力标签词汇)不动。
2. **api/ 增量类型**:`EventSubscription`(订阅句柄)、`SessionEventView`(sealed 不可变快照族,七事件各一 record)、`SessionRecipe`、`SessionComponentProvider`(D14 双通道);`MatchModeProvider` 增 `default int requiredApiVersion() { return 1; }`(只增默认方法)。
3. **`ApiSurfaceTest`**:白名单与签名快照双断言(★44)——①`MiniGameApi` 全部方法签名只引用白名单类型;②白名单内类型的公开签名只增不改(反射快照)。白名单逐包清单在本子阶段落盘(07 §7.2 表的口径细化)。
4. **D2/D3/D4/D14 实现**:`MiniGameApiImpl` 增量均为薄委托(joinSession/leaveSession → SessionService;subscribeSessionEvents → 各 Session.events() 聚合 + 会话注册表遍历挂接,新会话创建时自动接入;registerCapability → CapabilityRegistry);provider 收录走 `ServiceRegisterEvent` 干跑合并校验。
5. **API_VERSION 与拒载样例**:框架 `onEnable` 日志输出 API_VERSION(= 3),记录每个 Provider 的 requiredApiVersion;样例低版本拒载(★46)。
6. **测试伴随插件**:第三方目录测试插件升级为**真实消费样例**(承担 ★41~★46、★51~★55;含禁 shade 构建断言)。
7. **★v1.2 地图注册**:`MapRegistry` 增第二输入(显式注册汇入同一私有 `register()`、同一命名空间);`MiniGameApi#registerMap/unregisterMap` 薄委托;注册期校验(id 查重点名先到者/tags/模板目录存在性);卸载守卫(有会话正用 → 摘除被拒)+ `PluginDisableEvent` 兜底;`MapRegistrationTest`;测试伴随插件带一张注册式地图作消费样例(onEnable 顺序:解包模板 → 构造 MapDefinition → registerMap,14.39)。

**不做**(G2 范围):Gradle 双工程、depend 接线、`PluginDisableEvent` 摘除路径、预算观测(→ 8.1)。**不改变**:引擎内部机制(会话/切换/世界/持久化/三通道/svc 冻结/两级挂载)零改动;★1~★40 断言零放宽(仅包名模式与 ★40 增款:服务不得 import `api/**`)。

## 4. 关键实现要点

- **只增不改**:v1 面既有方法签名一字不动;`SwitchResult` 拒绝码、`JoinResult` 语义直接复用(D2 是 `SessionService#join/leave` 的受控暴露,不是第二套裁决)。
- **快照纪律**:`SessionEventView` 七 record 全是不可变值;不泄漏活会话/活组件引用(镜像 ★29 现取不缓存);订阅者异常隔离镜像总线既有隔离(★43)。
- **D14 防线四件套**:注册期干跑校验 → 装配期 `verifyDependencies` → 运行期 quarantine(★30)→ 预算告警(**观测实现落 8.1**;本子阶段先把 D9③ 的挂钩点留给 EngineTicker,不实现计时)。
- **彩排纪律(形态 A)**:宿主代码只用白名单 + L0 装配点;仅 L0 装配/监听/命令三处豁免可触内部面——review 驳回一切绕行写法。
- **服务不经 `MiniGameApi`**(D10):实现 D2 时同步落 ArchUnit 增款,防"第四通道"先例。
