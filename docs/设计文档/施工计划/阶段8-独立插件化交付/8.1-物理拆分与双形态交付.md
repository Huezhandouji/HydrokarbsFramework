## 4. 关键实现要点

- **拆分不改引擎**:切缝即既有分层线(engine 不 import mode/component 的 ArchUnit 断言原样有效);任何"拆分顺手改引擎"的 diff 按回流驳回。
- **Bukkit 依赖停序保证**:依赖者(玩法)先停、框架后停——摘除路径据此设计;框架 disable 走既有 `EngineTicker.close()`(取消任务 → dissolve 全部会话 → services.shutdown() → api 注销)。
- **预算观测只记不熔断**:慢 tick 数据同时服务于 Q4 裁决(观察后再裁);WARNING 内容必须点名提供方插件,让服主能定位第三方。
- **双形态等价复跑**:同一验收集(★1~★55,随验收追加同步扩)分别在形态 A 与形态 B 产物上执行,结论必须一致;不一致即修接线,不允许按形态分叉断言。
