# SHDF 玩法线施工计划总览

> 本文件夹是 **SHDF 玩法线**(宿主扩展接入 + 具体玩法实现)的**施工序列化**,接收自 SHDFMatch 设计案 v4.1(HydroKarbs MiniGame Framework v1.0 重构)原施工计划中整体迁出的玩法子阶段:**阶段3 全部(角色桥接与角色组件,本目录)、阶段5 玩法半段 5.1/5.2(TDM 首模式,本目录)、阶段6 全部(回合制与首领战,本目录),以及阶段2 的 2.5(大厅模式与最小闭环)与阶段7 的 7.3(旧插件迁移替换)**,共 13 个子阶段;子阶段文档沿用原七段模板(目标 / 前置与依赖 / 施工步骤 / 关键实现要点 / 陷阱与纪律 / 测试与验收 / 完成定义 DoD)。
> **框架线施工计划在 `../../施工计划/`**(HydroKarbs MiniGame Framework,v1.2 现行):玩法线**依赖框架线阶段 1/2/4 与 5.3/5.4** 的出口闸门,依赖明细见本文 §2;框架篇目在 `../../`(设计文档 00~20),玩法篇目在 `../`(04/05/08/09)。
> **出口闸门沿用框架/玩法两线同一套 §16.2 ★ 验收编号**(现为 ★1~★55 共 55 条,不拆分不重排;归属口径见 `../../施工计划/README.md` §4);哪些验收在本线建立、哪些为框架线建立后的本线复验,见本文 §3。
> **★v1.1/v1.2 对齐注**:本目录子阶段文档原文写定于 v1.0(单 jar 形态),未随 v1.1(框架独立插件化拆分,`../../19-v1.1修正案-框架独立插件化拆分与API面扩充.md`)与 v1.2(地图注册,`../../20-v1.2修正案-地图注册通道.md`)改写。施工时按 [`../README.md`](../README.md)「v1.1/v1.2 对齐注」重读旧口径:①包根 `com.shdf.match.*` → 框架类 `com.hydrokarbs.*` / 宿主类 `com.shdf.*`(D13,框架线 7.5 全库更名;含 `META-INF/services` 路径);②宿主自有主类(旧名 `SHDFMatchPlugin` 已废,不再共用框架主类);③宿主消费框架一律走 `MiniGameApi` 白名单面(形态 A 下仅 L0 装配/监听/命令三处豁免),`onEnable` 首行查 `API_VERSION`(v1.2 = 3,14.36);④禁 shade(14.35);⑤验收编号现为 ★1~★55(旧文"40 条"为 v1.0 时点数)。
> v4/v4.1 变更(会话级组件层、进程级服务层)对玩法线子阶段的影响标注(如 3.3 的 CapabilityRegistry 注册者注)沿用 `../../施工计划/README.md` §7/§8 的既有清单,不在此重复。
