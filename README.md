# Hydrokarbs MiniGame Framework(HKF)

Minecraft 小游戏框架:引擎只提供「实例容器 + 组件派发 + 端口」,一切玩法状态机
(阶段/结束/规则)以组件形态接入;模式是纯数据聚合根,新增模式零改引擎。
当前处于**阶段 1(引擎内核与架构地基)**施工中——契约类型、实例容器、节拍器已落盘,
架构验收测试(分层冻结/聚合根纯度/引擎内容盲)已建立。

> **测试即架构:★ 验收测试建立后永久生效,放宽断言须 PR 单独说明理由(施工计划 §3-4)。**
> 分层/纯度/封闭类断言的失败不是噪音,是架构回流的警报——正确动作永远是改代码,
> 不是改断言。

## 构建与测试

```bash
./gradlew build    # 全量构建(编译 + 测试 + shadow 打包)
./gradlew test     # 仅离线测试(无需活服;含架构冻结测试)
```

- 基线:Java 21 / PaperMC 1.21.11 / Gradle Kotlin DSL。
- 测试全部离线可跑:零 Bukkit import,Bukkit 类型位置一律传 null。
